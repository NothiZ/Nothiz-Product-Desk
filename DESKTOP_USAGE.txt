产品详情生成 · Windows 桌面版

运行环境：Windows 10/11，64 位，需要联网。
本程序已附带 Python、依赖库和 Chromium，不需要另装 Python 或浏览器。

使用方法
1. 解压整个 ProductDetailsDesktop 文件夹，双击 ProductDetailsDesktop.exe。
   请保留旁边的 _internal 文件夹，不要只复制 exe。
   首次启动时，选择 ProductDetailsDesktop 数据文件夹的存放位置。
2. 在“输入模板.xlsx”的“链接”列填入商品链接，或选择你现有的 Excel 文件。
3. 程序默认在输入表所在目录生成「输入表名_详情.xlsx」。点击“选择目录”可更改保存位置。
   如果同名输出属于其他输入表，或无法确认归属，请改选保存目录。
4. 选择 DeepSeek 或 Gemini，填入你自己的 API Key，并选择模型与详情模板。
   “在本机记住 API Key”只影响这台电脑的设置。
5. 首次使用或登录失效时，点击“阿里巴巴”或“淘宝 / 天猫”，在弹出的浏览器中登录，
   再回到程序点击“我已完成登录，继续”。
   淘宝、天猫共用一次登录流程；程序会继续完成天猫登录确认，必要时按提示补充确认。
6. 点击“开始生成”，在窗口中查看进度和日志；完成后点击“打开输出文件”。

内容检查与真失败
每条商品只生成一次文案，不因指定词或空内容自动重写；接口连接异常仍按原有网络机制重试。
“需检查”列只列出 OEM、批发、平台名称、LOGO 等命中的词，保留原文，正常计入成功，不影响断点续跑。
可在表格中逐条删改，或筛选“需检查”列集中处理；该列只是提示，不能替代人工审核。
“失败原因”列仅记录链接不支持、采集失败、接口调用失败或必要标题、详情缺失等真失败，成功行留空。
真失败仍保留可用的部分文案，下次续跑可补做；人工补齐四个文案字段后可复用修改结果，即使仍有指定词。

停止与保存
点击“停止并保存”后，程序不再开始新的商品任务，会等待正在处理的任务结束后保存。
AI 接口响应慢时，停止可能需要一些时间；请等待窗口提示完成。
输出表被 Excel 占用时，程序会尝试另存为 _backup.xlsx，窗口会显示实际保存位置。
“断点续跑”按链接复用完整文案，“需检查”不影响复用；真失败或不完整的行会重新处理。
需要重新生成所有商品时取消勾选，并确认输出目录。

数据位置
首次启动时选择数据文件夹的上级目录。例如选择 D:\工作数据，程序会在里面创建 ProductDetailsDesktop。
设置和账号登录状态保存在这个数据文件夹里。任务日志、候选图片、离线图片墙和选品结果.xlsx 保存在各自的任务目录里。
以后启动会自动使用该目录。
桌面窗口与命令行共用此数据目录。详情生成的输入和输出 Excel 保存在你选择的位置。
发布包不包含开发者的 API Key、登录态或真实商品表。

范围
支持 Alibaba、淘宝和天猫商品变体采集；淘宝、天猫需先登录，鞋码写入“尺寸”列，其他规格保留维度名称。
选项包含未选中及页面列出的售罄规格，不代表每个组合当前都有库存；无变体商品对应列可以为空。
不支持 1688、淘口令短链（m.tb.cn）或天猫国际（tmall.hk），请使用支持平台的商品详情页完整链接。
平台出现验证码时，可保持“显示浏览器”勾选，按浏览器提示手动处理。
