# Desktop edition implementation plan

> Execute independent GUI work with a subagent, then review spec compliance and code quality. Existing source remains untouched.

**Goal:** Deliver an independent, tested, Chinese Windows GUI and a redistributable onedir executable.
**Architecture:** Keep current acquisition and LLM logic. Use a Tkinter parent, hidden worker process, file-based logs/events, and optional progress/stop hooks.
**Tech stack:** Python 3.12, Tkinter/ttk, Scrapling 0.5.1, PyInstaller.

## Task 1: Copy and environment
- [x] Copy source/tests/docs into the permitted desktop workspace; exclude Git, virtualenv, private .env, login states and outputs.
- [x] Save original file hashes and create a local virtualenv with Tk available.
- [x] Install declared dependencies plus PyInstaller/Pillow into the copy only. Keep existing browser caches untouched.

## Task 2: Runtime and core adapter (controller)
- [x] Write failing tests for writable paths, validation, remembered-key choice and IPC key exclusion.
- [x] Implement desktop_runtime.py using the contract in the design.
- [x] Write failing tests for run progress, graceful stop, and GUI login confirmation.
- [x] Add minimal optional hooks to run.py, scraper.py and login.py; keep ai_writer.py and llm_client.py identical to source.
- [x] Implement desktop_worker.py with hidden-process logs, prompts and offline self-test.

## Task 3: Window (one implementer subagent)
- [x] Implement desktop_app.py against the runtime contract: Excel selectors, API settings, login actions, start/stop, progress/logs, open output.
- [x] Poll subprocess progress with Tk.after; never call worker code on the UI thread.
- [x] Handle startup failures, login confirmation, task errors and close-during-work safely.
- [x] Verify layout in a real window and add a lightweight UI smoke test.

## Task 4: Build and review
- [x] Add reproducible spec/build script, dedicated bundled Chromium resources, clean blank Excel template and release guide.
- [x] Run old/new offline tests and obtain independent spec/code reviews.
- [x] Build onedir executable, run frozen self-test with isolated browser/data/PATH, inspect GUI screenshot, and zip the entire release folder.
- [x] Verify original file hashes have not changed and no private data entered the release.
